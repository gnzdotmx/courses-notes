## Overview

This course is Google’s Agent Development Kit (ADK): what it is, how it works, and how to build agents that talk to other agents. Seven modules:

1. **Introduction**: scope, prerequisites, path through the course
2. **ADK Masterclass - Deep Dive**: concepts, components, development tools
3. **Hands-on Development**: first agent, external models, custom tools
4. **Sequential and Parallel Agents**: travel planner; blog writer
5. **Session and Memory & Structure Outputs**: context, persistence, structured outputs
6. **Callback Functions - Filtering and Guardrails**: callbacks; ADK Server API
7. **Wrap Up & Next Steps**: recap and what to do next

Goal: build agentic workflows in ADK, from a single agent through multi-agent systems with memory and guardrails.
