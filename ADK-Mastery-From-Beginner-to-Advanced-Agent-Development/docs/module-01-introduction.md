# Module 1: Introduction

## Objectives

- This course is Google ADK: what it is, how it works, and hands-on agentic workflows
- Python and LLM basics are assumed; the course does not teach Python
- Later modules go from one agent to multi-agent systems, memory, and guardrails

## Key concepts

| Term | Definition / notes |
| ---- | ------------------ |
| ADK (Agent Development Kit) | Google’s kit for building agents and the workflows between them |
| Agentic workflow | Agents that communicate with other agents and carry out tasks together |
| Python prerequisite | Basics to intermediate. The course assumes you can read and write Python |
| LLM / AI prerequisite | Fundamentals. Expert-level ML is not required |

## What you need before the labs

| You bring | Level | What this course will not do |
| --------- | ----- | ----------------------------- |
| Python | Basics or intermediate | Teach the language |
| Large language models and AI | Fundamentals | Require expert ML |
| Gaps | Look up what does not click, then come back | Reteach missing basics |

The explanations and tools for ADK itself are in the course. Missing Python or LLM basics are on you to fill.
