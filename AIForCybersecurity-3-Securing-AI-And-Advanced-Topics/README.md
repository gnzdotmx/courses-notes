## Overview

This course covers AI for credit card fraud detection and ways to stress-test and harden those models. Six modules:

1. **Course Introduction** — scope, GANs, attacks, and resilience
2. **Fraud Prevention with Cloud AI Solutions** — threats, cloud detection, metrics
3. **Introduction to Generative Adversarial Attacks (GANs)** — GAN basics and synthetic data
4. **GANs and Adversarial Attacks** — black-box and white-box attacks
5. **Reinforcement Learning** — RL for attacks; data engineering
6. **Evaluating AI Models and Performance** — features, optimization, metrics

Goal: build stronger fraud detectors and treat adversarial robustness as part of the workflow.
