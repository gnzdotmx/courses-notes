# Module 1: Course Introduction

## Objectives

- Advanced AI both strengthens defenses and gives attackers new tools
- Follow the path: fraud → GANs → attacks → RL → evaluation

## Key concepts

| Term | Definition / notes |
| ---- | ------------------ |
| Advanced AI for security | Techniques that improve defenses (e.g. fraud detection) and that attackers can also abuse |
| Cloud AI fraud prevention | Using cloud-based AI to detect and stop fraudulent activity |
| GAN (Generative Adversarial Network) | Model setup used here to craft sophisticated / adversarial attacks |
| Adversarial attack | Attack that targets ML models; GANs can help generate them; defenses matter too |
| Reinforcement learning (RL) | Learning via reward; used for adaptive, intelligent security behavior |
| Model evaluation | Measuring whether AI systems meet security and performance standards |
